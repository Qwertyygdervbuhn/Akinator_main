# Игра «Акинатор» на Python

## Что это такое?
Это наша крутая версия знаменитой игры «Акинатор». Вы загадываете персонажа, а компьютер задает вам вопросы и пытается угадать, кто это. 

**Авторы проекта:** Василечко Анастасия и Дмитрашко Александр.
**Наш Телеграм-бот:** @Akinatortestcsc31_bot

---

## Как в это играть?
У проекта есть два режима запуска:
1. **Программа на компе (GUI):** запускается красивое окно с кнопками и нарисованным Джинном.
2. **Бот в Телеграме:** можно играть прямо с телефона через чат.

---

## Главные фишки
* **Уже много знает:** прямо со старта Джинн может угадать больше 20 героев (Шрека, Наруто, Месси, Илона Маска, Куплинова и других).
* **Сам учится:** если Акинатор не угадает вашего героя, он не просто сдастся. Он спросит, кто это был, и попросит придумать вопрос, чтобы отличать его в будущем. Игра запишет всё в файл `akinator_db.json` и при следующем запуске уже будет знать этого персонажа!
* **Честная игра:** у Джинна есть всего 20 попыток (вопросов). Если за 20 шагов не угадал — он проиграл.
* **Игра компанией:** Телеграм-бот может играть с кучей людей одновременно и никого не запутает.

---

## Как устроены файлы внутри
Чтобы код не был кашей, мы разложили всё по полочкам:
* `config.py` — тут хранятся настройки (лимит в 20 вопросов и имя файла базы данных).
* `main.py` — файл для запуска игры в окошке на компьютере.
* `bot_main.py` — файл для запуска Телеграм-бота.
* `src/models.py` — отвечает за базу данных (загружает и сохраняет файл JSON, строит дерево вопросов).
* `src/views.py` — отвечает за то, как выглядит окно (цвета, кнопки, лицо Джинна).
* `src/controllers.py` — логика игры для компьютера (считает шаги, переключает вопросы).
* `src/bot_controller.py` — логика для Телеграм-бота (чтобы он помнил, кому какой вопрос задавать).
