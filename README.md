# Игра «Акинатор» на Python (Бинарное дерево решений)

## Что это за проект?
Это самописный аналог знаменитой игры «Акинатор». Компьютер задает вопросы и пытается угадать, какого персонажа вы загадали.
В команде разработчиков: Василечко Анастасия,Дмитрашко Александр


Игра умеет работать в двух режимах:
1. **Обычная программа (десктопная)** — открывается красивое окно с кнопками и нарисованным Джинном.
2. **Телеграм-бот** — в игру можно играть прямо со смартфона через Telegram.

## Главные фишки
* **Огромная база на старте:** Игра сразу знает больше 20 популярных героев (от Месси и Илона Маска до Наруто, Куплинова и Шрека).
* **Игра умеет учиться:** Если Акинатор проиграет, он не просто сдается. Он спросит, кого вы загадали, и попросит подсказать вопрос, который отличает этого героя от других. После этого игра запоминает нового персонажа и записывает его в файл `akinator_db.json`. При следующем запуске игра станет умнее!
* **Лимит в 20 вопросов:** Всё как в настоящей игре. Если за 20 вопросов Джинн не угадал — он признает поражение и предлагает вам обучить его.
* **Мультиплеер в Telegram:** Бот может одновременно играть с кучей разных людей, не путая их вопросы между собой.

## Как устроены файлы (Архитектура)
Проект разделен на отдельные логические папки и файлы, чтобы в коде был порядок:
* `config.py` — здесь лежат настройки (имя файла базы данных и лимит вопросов).
* `main.py` — файл для запуска обычной версии на компьютере (с окном на Tkinter).
* `bot_main.py` — файл для запуска Телеграм-бота.
* `src/models.py` — здесь живет логика базы данных (загрузка и сохранение JSON-файла, структура дерева).
* `src/views.py` — отвечает за внешний вид окна (кнопки, цвета, градиент и процедурная отрисовка Джинна).
* `src/controllers.py` — мозг обычной версии игры (считает шаги, переключает вопросы).
* `src/bot_controller.py` — мозг Телеграм-бота (следит за тем, кто из пользователей на каком вопросе находится).
